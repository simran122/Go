# I/O in Go (`io` package)

**← [Back to INDEX](INDEX.md)**

The **`io`** package is about **reading** and **writing** data. It gives you **Reader** (something you read from) and **Writer** (something you write to), plus helpers like **ReadAll** and **Copy**. Files, HTTP, and the network all use these same ideas – so you learn once and use them everywhere.

**Concepts used in this page:** **Interfaces** ([14-interfaces.md](14-interfaces.md)) – Reader and Writer are interfaces. **Defer** and **panic** ([19-defer-panic-recover.md](19-defer-panic-recover.md)). Read those first if you haven’t.

---

## What is Reader and Writer?

**Reader** = **where data comes from**. Something you **read** from. A file you open for reading, the body of an HTTP request, a network connection, or a string in memory – if you can **read** bytes from it, it can be a **Reader**. In Go we say it has type **`io.Reader`** (it has a **Read** method; see [14-interfaces.md](14-interfaces.md) for interfaces).

**Writer** = **where data goes to**. Something you **write** to. A file you create, an HTTP response, a network connection, or a buffer in memory – if you can **write** bytes to it, it can be a **Writer**. In Go we say it has type **`io.Writer`** (it has a **Write** method).

**Why does this matter?** You can write one piece of code that works with a **file**, **HTTP**, or **network** – because they all look the same as Reader or Writer. You don’t have to learn a different way for each.

---

## How to use io.Writer

**Writer** has one method: **`Write(p []byte) (n int, err error)`**. You pass a **slice of bytes**; it writes them to the destination (file, HTTP response, etc.) and returns how many bytes it wrote and an error.

**Two main ways to write:**

1. **Write raw bytes:** **`w.Write(data)`** – **data** is **`[]byte`**. Use when you have bytes (e.g. from **ReadAll**, or **[]byte("hello")**).
2. **Write formatted text with fmt:** The **fmt** package has methods that take an **io.Writer** as the first argument and write to it: **`fmt.Fprint(w, args...)`**, **`fmt.Fprintln(w, args...)`**, **`fmt.Fprintf(w, format, args...)`**. Same as **Print** / **Println** / **Printf**, but output goes to **w** (file, stderr, HTTP, buffer). Use when you want **%s**, **%d**, etc. See [39-fmt.md](39-fmt.md).

**Common Writers:**

| What you use as `w` | Where the data goes |
|---------------------|----------------------|
| **`os.Stdout`** | Terminal (normal output) |
| **`os.Stderr`** | Terminal (error/log output) |
| **`*os.File`** (e.g. from **`os.Create`**) | A file on disk |
| **`http.ResponseWriter`** | HTTP response (browser) |
| **`bytes.Buffer`** | Memory (collect data, then use **buf.Bytes()** or **buf.String()**) |

**Example: write bytes to a file**

```go
f, err := os.Create("output.txt")
if err != nil {
    panic(err)
}
defer f.Close()

// f is io.Writer – write bytes to it
data := []byte("Hello, file!\n")
n, err := f.Write(data)
if err != nil {
    panic(err)
}
// n = number of bytes written
```

**Example: write formatted text to a file (or stderr, or HTTP)**

```go
f, _ := os.Create("log.txt")
defer f.Close()

// Same fmt.Fprintf you use for HTTP or stderr – f is a Writer
fmt.Fprintf(f, "User %s logged in\n", "Alice")
```

**Example: collect output in memory with bytes.Buffer**

```go
var buf bytes.Buffer
fmt.Fprintf(&buf, "Name: %s, Age: %d", "Bob", 30)
result := buf.String()  // "Name: Bob, Age: 30"
// or buf.Bytes() for []byte
```

- **`bytes.Buffer`** is a Writer (and a Reader). You write to it with **Write** or **Fprintf**; then you read back with **buf.Bytes()** or **buf.String()**.

## ReadAll – read everything

**What is `r`?** **`r`** is the **Reader** – the place you read from (e.g. a file, HTTP body). People often use **r** for “reader”.

**`io.ReadAll(r)`** reads **all** bytes from **r** until there is nothing left. It returns the bytes and an error. Use it when you want the **whole** content in memory (e.g. a small file or an HTTP body).

- **EOF** = “end of file” or “end of data” – no more bytes to read. **ReadAll** returns **nil** error when it finishes; it does not return EOF.

```go
package main

import (
    "io"
    "os"
)

func main() {
    f, _ := os.Open("file.txt")
    defer f.Close()

    // r = f (the file). ReadAll reads everything from the file into memory.
    data, err := io.ReadAll(f)
    if err != nil {
        panic(err)
    }
    // data is []byte – use string(data) for text
}
```

## Copy – copy from Reader to Writer

**What is `src` and `dst`?** **`src`** = **source** – where data **comes from** (a Reader). **`dst`** = **destination** – where data **goes to** (a Writer).

**`io.Copy(dst, src)`** copies **all** bytes from **src** into **dst** until there is nothing left or an error. It returns how many bytes were copied and an error. Use it to copy file → file, or HTTP body → file, etc.

```go
src, _ := os.Open("source.txt")
defer src.Close()
dst, _ := os.Create("dest.txt")
defer dst.Close()

// dst = where to write, src = where to read from. Copy moves all data from source.txt to dest.txt.
n, err := io.Copy(dst, src)
if err != nil {
    panic(err)
}
// n = number of bytes copied
```

---

## CopyN – copy exactly N bytes

**`io.CopyN(dst, src, n)`** copies **at most n** bytes from **src** (source) to **dst** (destination). Same idea as **Copy**, but it stops after **n** bytes. Returns how many bytes were copied and an error.

```go
n, err := io.CopyN(dst, src, 100)  // copy at most 100 bytes
```

---

## ReadAtLeast and ReadFull

**`io.ReadAtLeast(r, buf, min)`** reads **at least min** bytes from **r** into **buf**. If there are fewer bytes (e.g. data ends early), it returns an error.

**`io.ReadFull(r, buf)`** reads **exactly** enough bytes to fill **buf** (same as “at least len(buf) bytes”). If there isn’t enough data, it returns an error. Use when you need a fixed number of bytes.

```go
buf := make([]byte, 10)
n, err := io.ReadFull(r, buf)  // must get 10 bytes; error if less
```

---

## Discard – throw away data

**`io.Discard`** is a **Writer** that **throws away** everything you write to it. Use it when you need to **read** from something (e.g. an HTTP response body) but you **don’t care** about the data – you just want to “drain” it so you can close or reuse the connection.

```go
// Copy from resp.Body into Discard = read the body and throw it away
io.Copy(io.Discard, resp.Body)
```

---

## MultiWriter – write to many

**`io.MultiWriter(w1, w2, ...)`** gives you **one** Writer that sends the same data to **all** of **w1**, **w2**, etc. When you write to it, the data goes to the screen **and** the file (or whatever you passed). Use it when you want to log to a file and print to the screen at the same time.

```go
f, _ := os.Create("log.txt")
defer f.Close()
w := io.MultiWriter(os.Stdout, f)  // w = “write to screen and file”
fmt.Fprintln(w, "This goes to screen and file")
```

---

## MultiReader – read from many

**`io.MultiReader(r1, r2, ...)`** gives you **one** Reader that reads from **r1** until there is nothing left, then from **r2**, and so on. So you treat several sources as one long stream.

```go
r := io.MultiReader(strings.NewReader("Hello "), strings.NewReader("World"))
data, _ := io.ReadAll(r)
fmt.Println(string(data))  // Hello World
```

---

## LimitReader – read at most N bytes

**`io.LimitReader(r, n)`** wraps **r** so that reading from it gives **at most n** bytes. After that, it acts like there is no more data. Use it when you want to cap how much you read (e.g. to avoid reading a huge file into memory).

```go
r := io.LimitReader(strings.NewReader("Hello World"), 5)
data, _ := io.ReadAll(r)
fmt.Println(string(data))  // Hello (only 5 bytes)
```

## Summary

| Task | Function / type |
|------|------------------|
| Read all | **`io.ReadAll(r)`** |
| Copy | **`io.Copy(dst, src)`**, **`io.CopyN(dst, src, n)`** |
| Read exactly | **`io.ReadFull(r, buf)`**, **`io.ReadAtLeast(r, buf, min)`** |
| Discard | **`io.Discard`** (Writer) |
| Multi write | **`io.MultiWriter(w1, w2, ...)`** |
| Multi read | **`io.MultiReader(r1, r2, ...)`** |
| Limit read | **`io.LimitReader(r, n)`** |
| EOF | **`io.EOF`** (end of stream) |
