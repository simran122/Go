# I/O in Go (`io` package)

**← [Back to INDEX](INDEX.md)**

The **`io`** package defines **Reader** and **Writer** and common functions like **ReadAll** and **Copy**. Many Go APIs (files, HTTP, network) use these types. Everything is in simple language.

**Concepts used in this page:** We use **interfaces** ([14-interfaces.md](14-interfaces.md)) – Reader and Writer are interfaces. We also use **defer** ([19-defer-panic-recover.md](19-defer-panic-recover.md)) and **panic** ([19-defer-panic-recover.md](19-defer-panic-recover.md)). Read those first if you haven’t.

---

## What is Reader and Writer?

- **`io.Reader`** – something you **read** from. It has a **`Read`** method. Files, HTTP body, network connections, **bytes.Buffer**, and **strings.Reader** all work as **Reader** (they have the right method – that’s what “implement” means; see [14-interfaces.md](14-interfaces.md)).
- **`io.Writer`** – something you **write** to. It has a **`Write`** method. Files, HTTP response, network connections, and **bytes.Buffer** work as **Writer**.

So you can write code that works with **any** Reader or Writer (file, network, buffer) without caring which one it is.

---

## ReadAll – read everything

**`io.ReadAll(r io.Reader)`** reads **all** bytes from **r** until **EOF**. Returns **`([]byte, error)`**. Use when you want the whole content in memory (e.g. small file or HTTP body).

```go
package main

import (
    "io"
    "os"
)

func main() {
    f, _ := os.Open("file.txt")
    defer f.Close()
    data, err := io.ReadAll(f)
    if err != nil {
        panic(err)
    }
    // data is []byte – use string(data) for text
}
```

- **`io.EOF`** – error value meaning "end of file"; **ReadAll** returns **nil** error when it finishes reading, not **EOF**.

---

## Copy – copy from Reader to Writer

**`io.Copy(dst io.Writer, src io.Reader)`** copies from **src** to **dst** until **EOF** or error. Returns **`(written int64, err error)`**. Use to copy file to file, or HTTP body to file, etc.

```go
src, _ := os.Open("source.txt")
defer src.Close()
dst, _ := os.Create("dest.txt")
defer dst.Close()
n, err := io.Copy(dst, src)
if err != nil {
    panic(err)
}
// n = number of bytes copied
```

---

## CopyN – copy exactly N bytes

**`io.CopyN(dst, src, n)`** copies **at most n** bytes from **src** to **dst**. Returns **`(written int64, err error)`**.

```go
n, err := io.CopyN(dst, src, 100)  // copy at most 100 bytes
```

---

## ReadAtLeast and ReadFull

**`io.ReadAtLeast(r, buf, min)`** reads **at least min** bytes into **buf**. Returns error if fewer bytes are read (e.g. EOF before min).  
**`io.ReadFull(r, buf)`** reads **exactly len(buf)** bytes. Same as **ReadAtLeast(r, buf, len(buf))** – fails if not enough data.

```go
buf := make([]byte, 10)
n, err := io.ReadFull(r, buf)  // must get 10 bytes
```

---

## Discard – throw away data

**`io.Discard`** is an **io.Writer** that throws away everything written to it. Use when you need to **read** from a Reader but don’t care about the data (e.g. drain a response body).

```go
io.Copy(io.Discard, resp.Body)  // read and discard body
```

---

## MultiWriter – write to many

**`io.MultiWriter(w1, w2, ...)`** returns an **io.Writer** that writes to **all** of **w1**, **w2**, etc. Use to log and write to file at the same time.

```go
f, _ := os.Create("log.txt")
defer f.Close()
w := io.MultiWriter(os.Stdout, f)
fmt.Fprintln(w, "This goes to screen and file")
```

---

## MultiReader – read from many

**`io.MultiReader(r1, r2, ...)`** returns an **io.Reader** that reads from **r1** until EOF, then **r2**, etc.

```go
r := io.MultiReader(strings.NewReader("Hello "), strings.NewReader("World"))
data, _ := io.ReadAll(r)
fmt.Println(string(data))  // Hello World
```

---

## LimitReader – read at most N bytes

**`io.LimitReader(r, n)`** returns an **io.Reader** that reads **at most n** bytes from **r**. After n bytes it returns **EOF**.

```go
r := io.LimitReader(strings.NewReader("Hello World"), 5)
data, _ := io.ReadAll(r)
fmt.Println(string(data))  // Hello
```

---

## Summary

| Task | Function / type |
|------|------------------|
| Read all | **`io.ReadAll(r)`** |
| Copy | **`io.Copy(dst, src)`**, **`io.CopyN(dst, src, n)`** |
| Read exactly | **`io.ReadFull(r, buf)`**, **`io.ReadAtLeast(r, buf, min)`** |
| Discard | **`io.Discard`** (Writer) |
| Multi write | **`io.MultiWriter(w1, w2, ...)`** |
| Multi read | **`io.MultiReader(r1, r2, ...)`** |
| Limit read | **`io.LimitReader(r, n)`** |
| EOF | **`io.EOF`** (end of stream) |
